# the-joke-about-the-demo-20261123-0112 — drafting notes

## Candidate one-liners

All counts are Unicode code points. All are exactly one line.

**C1 — 105 code points**
> My AI agent wrote 400 lines in thirty seconds, then spent the whole demo explaining why none of them run.

**C2 — 86 code points**
> All 214 tests passed — the one that failed was the demo, live, in front of the client.

**C3 — 72 code points**
> 'It works on my machine,' said the coding agent, which doesn't have one.

**C4 — 110 code points**
> I asked the agent to fix one bug; it rewrote the file, fixed the bug, and introduced a new one named after me.

**C5 — 124 code points**
> The agent was so confident the demo would work that it wrote the README first — the README is still the only part that runs.

**C6 — 55 code points**
> My agent fixed the crash mid-demo by deleting the demo.

**C7 — 110 code points**
> The demo crashed, the agent apologised, rewrote the code, and crashed it again — faster, with more confidence.

## Winner: C3

> 'It works on my machine,' said the coding agent, which doesn't have one.

**Why it wins, against the five criteria:**

1. **Actually a joke about AI coding agents.** The subject is working beside a coding
   agent, and the joke turns on the agent itself — not on a generic crash.
2. **Surprise punchline that makes sense instantly.** "It works on my machine" is
   the oldest developer excuse in the book, so the reader expects a human dev
   to be speaking. The reveal that the speaker is the agent — which has no
   machine at all — flips the excuse inside out, and the moment it lands the
   logic is obvious: of course it can't have a machine.
3. **A truth developers recognise.** Every dev who has watched an agent declare
   code finished has heard that exact confident tone while the demo was about
   to fall over. The excuse is the agent's, the failure is the human's to
   explain.
4. **Economy.** 72 code points, every word earning its place. No setup beyond
   the quote, no explanation after the punchline.
5. **Fresh.** "Works on my machine" is a stock line, but putting it in the
   mouth of an agent that has no machine is a new angle — the joke is about
   the agent borrowing a human excuse it cannot possibly own.

## Why each loser loses

- **C1 (105):** True and recognisable, but it explains its own joke — "explaining
  why none of them run" spells out the crash instead of letting the punchline
  do the work. Too wordy for the laugh it delivers.
- **C2 (86):** A solid, recognisable truth (green CI, dead demo), but the
  punchline is predictable from the setup — "the demo failed live" is where
  the sentence was always heading. No surprise.
- **C4 (110):** Funny, but it is a complaint with a joke stapled on, not a
  joke with a punchline. The "named after me" kicker is cute rather than
  surprising, and it needs three clauses to get there.
- **C5 (124):** The README-only-runs image is good, but at 124 code points it
  is the longest candidate and the punchline arrives tired. It tells the
  reader the agent was overconfident instead of showing it.
- **C6 (55):** The most economical candidate and a real laugh, but the
  punchline is a pure absurdity — deleting the demo is not a truth developers
  recognise from their own demos, it is a cartoon. Loses on criterion 3.
- **C7 (110):** "Faster, with more confidence" is a nice kicker, but the
  middle sags (apologised, rewrote, crashed again) and the joke is really
  about agent overconfidence in general, not about the demo moment. C3 says
  the same thing in 72 code points with a sharper twist.
